Wi-Fi RTT Indoor Positioning Pipeline

Official repository containing the MATLAB implementation and experimental evaluation framework for indoor localization using IEEE 802.11mc Wi-Fi Round-Trip Time (RTT). The system integrates Difference-to-the-Closest (DtC) hardware offset cancellation, dynamic Min-Max scaling, Null Occlusion Radio Imputation (NORI 1.5), and supervised Machine Learning models evaluated under rigorous cross-device and spatial cross-validation schemes.

Scripts and Repository Structure:

1. `PIPELINE_OFICIAL.m`
Main Machine Learning Pipeline (Cross-Device Evaluation):  
  Automates data ingestion, preprocessing, training, and evaluation across heterogeneous mobile devices (Poco F2 Pro and Samsung Galaxy S24 Ultra).
  * Converts `.mat` database structures into normalized tabular predictors (`Ant1` to `Ant4`) and 2D spatial targets (`PosX`, `PosY`).
  * Implements burst-by-burst DtC transformation by subtracting the minimum observed RTT distance per vector.
  * Applies Min-Max normalization using training bounds to prevent data leakage.
  * Executes NORI (1.5) imputation to penalize missing packet dropouts ($\text{NaN}$) deterministically.
  * Trains and benchmarks four regression models: Fine Tree, Bagged Trees (200 learners), Gaussian SVM, and Optimizable Tree.
  * Computes Mean Positioning Error ($E_m$), 90th percentile error ($P_{90}$), and training/inference execution times.

2. `tablasfold.m`
Spatial Dataset Partitioner (Coordinate Filtering):  
  Structures and partitions the continuous measurement datasets into 5 strictly disjoint geographic splits.
  * Maps the 20 reference points (RPs) into 5 predefined coordinate folds (4 spatial points per fold).
  * Employs spatial tolerance filtering (`filtrar_tol`) to isolate training and test coordinates without temporal overlap.
  * Generates the structured `dataset_completo` variable containing the 5 blind test splits per dataset pair.

3. `PIPELINE_OFICIAL_KFOLD.m`
Spatial K$-Fold Cross-Validation for ML Regressors (K=5):  
  Evaluates the generalization and spatial interpolation capabilities of the supervised ML algorithms when predicting coordinates in unseen physical blind zones.
  * Partitions the physical floor coordinates into disjoint blocks, withholding 20% of the surveyed area in each fold.
  * Enforces blind cross-device testing: trains on Device A (known coordinates) and evaluates on Device B (unseen blind folds).
  * Computes the mean error ($E_m$) and standard deviation ($\sigma$) across all 5 folds to audit spatial generalizability.

4. `c5_bucleMejor.m`
k$-NN Baseline Optimization (Configuration 5 Grid Search):  
  Replicates the metric-space baseline through a comprehensive 3D hyperparameter sweep over temporal aggregation datasets (`RAW`, `W1S`, `AVE`).
  * Iterates across 6 distance metrics: *City Block*, *Euclidean*, *Minkowski-3*, *Cosine*, *Sorensen*, and *Neyman*.
  * Sweeps odd neighborhood densities ($k \in [1, 3, \dots, 51]$).
  * Evaluates 3 weighting formulations: unweighted, inverse distance, and squared inverse distance.
  * Automatically identifies the optimal configuration minimizing positioning error for each device pair.

5. `c5_coordenada.m`
Spatial $K$-Fold Evaluation for $k$-NN (Configuration 5): 
  Applies the optimal $k$-NN Configuration 5 algorithm directly onto the spatially partitioned splits generated by `tablasfold.m`.
  * Evaluates metric-space matching over coordinates omitted from the calibration radio map.
  * Reports fold-by-fold Mean Absolute Error (MAE), $P_{90}$, and total search time per split to quantify the latency trade-off of lazy learners.

Prerequisites & Execution

1. System Requirements:
   * MATLAB R2023a or newer.
   * Statistics and Machine Learning Toolbox.
2. Directory Setup:
   * Place the experiment databases inside `databases/` or `../databases/` as referenced by the scripts.
   * Ensure the metric helper functions (`method_*`, `distance*`) are located in the `metodos/` directory.
3. Execution Workflow:
   * Run `PIPELINE_OFICIAL.m` for standard cross-device ML benchmarks.
   * Execute `tablasfold.m` followed by `c5_coordenada.m` to reproduce $k$-NN spatial validation.
   * Run `PIPELINE_OFICIAL_KFOLD.m` to audit tree and kernel models under spatial blind spots.
